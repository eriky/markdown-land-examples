# Markdown Land examples

Example files for the Markdown tutorials on [markdown.land](https://markdown.land). Every snippet in this repository is plain Markdown, so you can open the raw files to see how each example is written.

## Getting started

This repository has no code to install. It's a collection of Markdown examples that show how GitHub renders them.

### Installation

Clone the repository to try the examples locally:

```bash
git clone https://github.com/eriky/markdown-land-examples.git
```

### Configuration

There's nothing to configure. Open any `.md` file in your editor and compare it with the rendered version on GitHub.

## What's new in v2.0?

This heading shows how GitHub removes punctuation from heading anchors: the link to this section is `#whats-new-in-v20`.

## Q&A / FAQ

The `&` and `/` disappear from the anchor, but both spaces become hyphens: `#qa--faq`.

## 🚀 Quick start

An emoji at the start of a heading leaves a leading hyphen in the anchor: `#-quick-start`.
