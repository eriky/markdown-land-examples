# Colored text on GitHub

GitHub strips `style` attributes, so the only way to color words is LaTeX math. See [markdown.land/markdown-color](https://markdown.land/markdown-color).

$\color{red}{\text{This text is red}}$

$\color{green}{\text{Green}}$, $\color{blue}{\text{blue}}$ and $\color{orange}{\text{orange}}$

$\textcolor{purple}{\text{textcolor works too}}$

$\color{#0969da}{\text{Any hex color}}$

$\colorbox{yellow}{Highlighted}$

$\fcolorbox{red}{yellow}{Framed}$
